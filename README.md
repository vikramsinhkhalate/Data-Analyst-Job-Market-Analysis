# Data Analyst Job Market Analysis

## Overview

Welcome to my analysis of the data job market, focusing on Data Analyst roles.

This project was created out of a desire to navigate and understand the job market more effectively. It explores the top-paying and in-demand skills to help identify optimal job opportunities for Data Analysts.

## The Questions

Below are the key questions I aim to answer through this project:

1. What are the skills most in demand for the top 3 most popular data roles?
2. How are in-demand skills trending for Data Analysts?
3. How well do jobs and skills pay for Data Analysts?
4. What are the optimal skills for Data Analysts to learn? (High Demand AND High Paying)

## Tools I Used

For my deep dive into the Data Analyst job market, I used several key tools:

- **Python:** The backbone of my analysis, allowing me to analyze the data and uncover critical insights.
  - **Pandas:** Used for data manipulation and analysis.
  - **Matplotlib:** Used for data visualization.
  - **Seaborn:** Used to create advanced and informative visualizations.

- **Jupyter Notebooks:** Used to write and execute Python scripts while documenting notes and analysis.

## Project Structure

1. **Exploratory Data Analysis:** Initial exploration of the job-market dataset.
2. **Skill Demand:** Analysis of the most in-demand skills.
3. **Skills Trend:** Examination of changing skill requirements for Data Analysts.
4. **Salary Analysis:** Analysis of salaries across jobs and skills.
5. **Optimal Skills:** Identification of skills that combine high demand and high salaries.
